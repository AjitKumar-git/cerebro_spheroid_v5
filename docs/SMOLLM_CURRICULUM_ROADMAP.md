## 2. SmolLM2 Pretraining Data Recipe (arXiv:2502.02737)

SmolLM2 demonstrates that pretraining performance is maximized by a 4-stage data curriculum where code and mathematics are progressively phased in, with high-quality synthetic textbooks introduced during the final annealing phase:

```
                              ┌────────────────────────────────────────┐
                              │    SMOLLM2 PRE-TRAINING CURRICULUM     │
                              │           (4-Stage Mixture)            │
                              └───────────────────┬────────────────────┘
          ┌───────────────────┬───────────────────┼───────────────────┬───────────────────┐
          ▼                   ▼                   ▼                   ▼                   ▼
┌───────────────────┐ ┌───────────────────┐ ┌───────────────────┐ ┌───────────────────┐ ┌───────────────────┐
│ 1. Stage 1 (<55%) │ │ 2. Stage 2 (55-73)│ │ 3. Stage 3 (73-91)│ │ 4. Stage 4 (91+)  │ │ Pretraining Rule: │
│    90% English Web│ │    75% English Web│ │    70% English Web│ │    58% English Web│ │ 100% Loss-Bearing │
│    10% The Stack  │ │    20% The Stack  │ │    20% The Stack  │ │    24% The Stack  │ │ Zero Prompt Mask │
│     0% Math       │ │     5% FineMath   │ │    10% FineMath   │ │    14% FineMath   │ │ Zero SFT/Tools    │
│     0% Synthetic  │ │     0% Synthetic  │ │     0% Synthetic  │ │     4% Cosmopedia │ │ (Free Rambling)   │
└───────────────────┘ └───────────────────┘ └───────────────────┘ └───────────────────┘ └───────────────────┘
```

1. **English Web (`FineWeb` / `FineWeb-Edu`)**:
   - Web pages filtered using educational quality classifiers.
   - Foundation for general knowledge, syntactic variety, and factual fluency.
2. **Code (`The Stack-Edu` / `StarCoderData`)**:
   - Clean Python, algorithmic implementations, and structured software repositories.
   - Grows from 10% in Stage 1 to 24% during Stage 4 annealing.
3. **Mathematics (`FineMath` / `Open-Web-Math`)**:
   - Step-by-step mathematical proofs, arithmetic calculations, and deductive problem solving.
   - Introduced in Stage 2 (5%) and scaled to 14% in Stage 4 annealing.
4. **Synthetic Curated Textbooks (`Cosmopedia v2`)**:
   - High-density pedagogical textbooks generated by frontier models, reserved for Stage 4 annealing (4%).

## 3. Data Integrity & Anti-Regression Invariants

1. **Zero Prompt Masking**: Every token in pretraining windows is loss-bearing. Never mask prompt sequences with `-100`.
2. **Zero SFT Contamination in Pretraining**:
   - Pretraining trains exclusively on continuous, self-contained documents.
   - Multi-turn instruction tuning and conversation templates are strictly reserved for post-pretraining SFT (`training/train_v5_sft.py`).
3. **Unrestricted Tool Exploration**:
   - During pretraining, tool loss is explicitly locked at $0.0$.
   - The model is allowed free generation of cognitive boundaries (`<think>`, `<tool_call>`) without penalization.
