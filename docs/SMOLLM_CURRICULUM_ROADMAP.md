## 3. The 1,000,000-Step Graded Developmental Schedule

The 1M steps map directly to **32.8 Billion tokens** using a sliding batch configuration:
- Sequence Length $L = 512$
- Effective Batch Size $B_{\text{eff}} = 64$ (e.g. Micro-batch 4 with Gradient Accumulation 16)
$$\text{Tokens per Step} = 64 \times 512 = \mathbf{32,768 \text{ tokens/step}}$$
$$\text{Total Tokens} = 1,000,000 \times 32,768 = \mathbf{32.77 \text{ Billion tokens}}$$

```
Step 0 ──────────────► 50k ─────────────────────────► 500k ────────────────────────► 900k ──────────► 1,000k
  PHASE 1 (1.6B tokens)       PHASE 2 (14.7B tokens)             PHASE 3 (13.1B tokens)       PHASE 4 (3.3B)
  Basic Syntax & Grammar      Knowledge & Multi-Step Reasoning   Modern Agentic Workflows     Energy Annealing
  Cosmopedia Stories          FineWeb-Edu + Math-CoT             SmolTalk + Python-Edu + Tools Replay + Halting
  LR: 0 -> 3e-4 (warmup)      LR: 3e-4 -> 1.5e-4 (cosine)        LR: 1.5e-4 -> 5e-5           LR: 5e-5 -> 1e-5
```

### Phase Breakdown

#### Phase 1: Foundation, Grammar & Low-Entropy Structure (Steps 0 $\rightarrow$ 50,000)
- **Token Volume:** 1.64 Billion tokens.
- **Data Mixture:** Cosmopedia v2 (Stories & Simple Textbooks) (70%) + Wikipedia Clean (30%).
- **Learning Rate:** Linear warmup $0 \rightarrow 3.0 \times 10^{-4}$ (first 2,000 steps), cosine decay to $2.5 \times 10^{-4}$.
- **Target Loss:** $10.4 \longrightarrow 3.8$.
- **Goal:** Learn the unigram, bigram, orthographic spelling, and syntactic foundations of English.

#### Phase 2: World Knowledge, Calculation & Scientific Reasoning (Steps 50,000 $\rightarrow$ 500,000)
- **Token Volume:** 14.75 Billion tokens.
- **Data Mixture:** FineWeb-Edu (score $\ge 3$) (50%), Open-Web-Math / GSM8K (25%), Python-Edu (15%), Cosmopedia (10%).
- **Learning Rate:** Cosine decay from $2.5 \times 10^{-4} \rightarrow 1.2 \times 10^{-4}$.
- **Target Loss:** $3.8 \longrightarrow 2.1$.
- **Goal:** Master domain facts, mathematical word problems, algorithmic logic, and relational premises.

#### Phase 3: Agentic Workflows, Tool-Use & Long Context Needles (Steps 500,000 $\rightarrow$ 900,000)
- **Token Volume:** 13.11 Billion tokens.
- **Data Mixture:** SmolTalk (Hermes Tool-Use + Magpie Reasoning) (40%), The Stack Python-Edu (35%), Needle-in-Haystack Multi-Turn Dialogue (25%).
- **Specialized Head:** `ToolActionHead` active training from Shell 31 (Chat, Bash, Python, FileRead, Calculator).
- **Learning Rate:** Cosine decay from $1.2 \times 10^{-4} \rightarrow 4.0 \times 10^{-5}$.
- **Target Loss:** $2.1 \longrightarrow 1.6$.
- **Goal:** Accurate tool dispatch, zero-hallucination execution, and long-range associative retrieval.

#### Phase 4: Model Consolidation, Replay & Energy Annealing (Steps 900,000 $\rightarrow$ 1,000,000)
- **Token Volume:** 3.27 Billion tokens.
- **Data Mixture:** Balanced high-value replay (25% Math, 25% Code, 25% Agentic, 25% Factual Knowledge).
- **Objective:** ACT Halting Gate stabilization ($\mathcal{L}_{\text{ponder}}$) + Fixed-Point Energy Guard ($\mathcal{L}_{\text{energy}}$).
- **Learning Rate:** Linear decay from $4.0 \times 10^{-5} \rightarrow 1.0 \times 10^{-5}$.
- **Target Loss:** $1.6 \longrightarrow \mathbf{1.35}$ (SmolLM parity).
